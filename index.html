Where I've built things

  • Worked on the migration of an enterprise application onto modern Vue and React, backed by Java and Spring Boot — from design review through implementation, testing and deployment.
  • Built interactive interfaces and dashboards in React and TypeScript, then chased down the things that make them feel slow: page speed, responsiveness, and the rough edges on high-impact business flows.
  • Developed a payment-status microservice in Java/Spring Boot — REST API design, schema changes, and integration with upstream payment gateways and downstream reporting. Handled retries, error paths and idempotency so transaction state stays consistent.
  • Designed GitHub Actions workflows that lint and test every pull request and build and push Docker images on merge, with branch protections and status checks that block deploys until everything passes.
  • Extended CI/CD with static analysis, security checks and a manual approval gate in front of production.
  • Led cross-layer troubleshooting across UI, APIs and the database using Datadog log metrics and ad-hoc SQL, validated fixes with stakeholders, and wrote post-incident notes.
  • Contributed to design discussions and sprint ceremonies on tradeoffs, risk and timelines.
  • Turned manual access approval and provisioning into guided, semi-automated flows with Vue.js — faster to complete, with more consistent audit trails.

  • Refactored and tuned PL/SQL behind reporting, provisioning and entitlement sync — simpler procedures, less redundant logic, faster nightly jobs.
  • Debugged production IAM issues with infrastructure and security teams, from UI validation bugs to authorization failures and inconsistent directory state.
